# Paras logo

Vector traces of the #25 wordmark and monogram (`apps/web/public/brand/`), flat colours, transparent background.

| Colour | Hex |
|---|---|
| Ink (light bg) | `#1C2026` |
| Ink (dark bg) | `#F1EBDD` |
| Gold stroke | `#C4923A` |
| Seal red | `#C4402C` |

- `svg/wordmark.svg`, `svg/monogram.svg`: for light backgrounds. `-dark` variants: for dark backgrounds.
- `png/`: transparent PNGs. Wordmark 512/1024/2048 px wide, monogram 64–1024 px.
- The seal's flower is a knockout (shows the background).
